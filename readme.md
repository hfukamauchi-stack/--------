# ①課題名
8BIT JANKEN（レトロじゃんけんアプリ）

## ②課題内容（どんな作品か）
- CPUとグー・チョキ・パーで対戦するシンプルなじゃんけんアプリ。
- 1980年代のゲームをイメージした8bit風のレトロなデザインを採用し、昔のゲーム機のような雰囲気を楽しめる作品。

## ⑤工夫した点・こだわった点
- 8bitゲームをイメージし、背景色やボタン、フォントなどを工夫してレトロなゲーム画面を表現した。
- グー・チョキ・パーのボタンを押すことでCPUがランダムに手を選び、勝敗が判定される仕組みを実装した。
- CSSを活用し、ボタンの色や押した際の動きなど、操作していて楽しくなるデザインを意識した。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- JavaScriptを用いて、ユーザーとCPUの選択に応じた勝敗判定を実装すること。
- HTMLで作成した要素にCSSを適用し、イメージしていたレトロなゲームデザインに近づけること。
- 今後は連勝記録やスコア機能、勝敗に応じた演出などを追加し、よりゲーム性の高いアプリに発展させたい。
